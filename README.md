# 云流量安全分析原型系统

**云流量安全分析原型系统**是一个面向云上网络安全运营场景的前端原型项目，重点呈现云内外流量态势、威胁告警、场景化安全分析、资产风险定位与溯源研判等能力。项目当前定位为**静态前端演示系统**，适用于产品方案汇报、交互原型验证、安全运营流程展示与后续工程化改造前的需求对齐。

> 本项目不依赖真实后端服务或生产安全数据。页面中的指标、事件、资产、告警、证据字段与处置动作均为原型演示数据，用于说明系统的信息架构、分析链路和交互形态。

## 项目概览

系统采用企业级安全运营控制台风格，以深蓝侧边导航、白色内容卡片、浅蓝信息层级、趋势图表和详情抽屉构建主要交互体验。整体设计强调**态势总览—告警发现—场景分析—详情研判—处置联动**的安全运营流程，使用户能够在一个统一界面中理解云网络流量风险、受影响资产和建议处置动作。

## 核心能力

系统围绕云上流量安全监测与威胁运营分析构建多个一级模块。各模块并非孤立页面，而是共同组成从态势感知到事件研判的完整工作流。用户可以先在态势总览中识别整体风险，再进入实时告警或场景分析模块查看具体事件，最后通过详情抽屉查看证据字段、进程信息、资产上下文与处置建议。

| 一级模块 | 功能定位 | 主要内容 |
| --- | --- | --- |
| 态势概览 | 展示云内外流量安全态势与攻击趋势 | 攻击趋势折线图、受攻击区域、物理机、云主机、容器等统计指标 |
| 实时告警 | 展示云上安全事件与告警处置状态 | 告警列表、风险等级、攻击向量、资产信息、处置状态与详情抽屉 |
| 场景分析 | 按业务安全场景组织事件分析能力 | 六类子模块、统计项、查询项、事件列表、详情研判信息 |
| 威胁监测 | 聚焦威胁行为与检测结果 | 攻击源排行、趋势统计、检测层面分布、风险等级分析 |
| 威胁情报 | 展示外部威胁线索与情报研判 | IOC、攻击组织、攻击行为、情报标签与影响范围 |
| 风险定位 | 定位高风险资产与攻击路径 | 资产风险、影响范围、区域分布、风险热区 |
| 溯源分析 | 支撑安全事件溯源与攻击链还原 | 攻击路径、事件时间线、源端信息与受害资产关系 |
| 资产管理 | 管理云上基础资源与风险资产 | Region、VPC、物理机、云主机、容器等资源清单 |
| 业务规则 | 展示安全检测与业务规则配置 | 规则列表、风险策略、命中情况与管理入口 |
| 威胁预警 | 展示安全预警与趋势研判 | 预警指标、趋势信息、重点资产与风险提示 |

## 场景分析模块

本轮重点新增的**场景分析**作为侧边栏一级模块呈现，不归入威胁分析或其他已有分组。模块内部以安全运营人员常见研判对象为线索，拆分为六个子模块，并统一提供统计、检索、列表与详情四类信息结构。

| 子模块 | 关注对象 | 示例分析重点 |
| --- | --- | --- |
| 数据库行为分析 | 数据库访问、异常查询、敏感操作 | 高危 SQL、异常来源、账号行为、敏感表访问 |
| WEB 服务器分析 | Web 入口、访问路径、攻击请求 | WebShell、目录扫描、异常参数、漏洞利用证据 |
| 非常规服务分析 | 非标准端口、临时服务、异常监听 | 端口暴露、反连行为、调试容器、异常进程 |
| 登录行为分析 | 登录来源、身份认证、账号异常 | 异地登录、暴力破解、权限提升、可疑终端 |
| 挖矿行为分析 | 挖矿进程、矿池连接、资源异常 | 高 CPU、矿池域名、恶意脚本、持久化路径 |
| 邮件安全分析 | 邮件投递、附件、链接与账号风险 | 钓鱼邮件、恶意附件、异常转发、凭证泄露 |

每个子模块均采用同一条原型链路：页面顶部提供汇总统计，中部提供筛选与查询入口，下方展示事件列表，点击事件后通过详情抽屉呈现事件摘要、证据字段、影响资产、研判建议和联动处置按钮。这种结构有助于在产品评审阶段快速验证安全分析人员的真实工作流。

## 本地运行

请确保本地已安装 Node.js 与 pnpm。进入项目根目录后，按照以下步骤启动开发服务。

```bash
pnpm install
pnpm dev
```

开发服务启动后，可在终端输出的本地地址中访问系统页面。若需要生成生产构建，可以执行以下命令。

```bash
pnpm build
```

如果需要预览生产构建产物，可执行以下命令。

```bash
pnpm preview
```

## 设计说明

界面采用深蓝安全控制台侧边栏与浅色内容面板组合，以降低大屏信息密度带来的阅读负担。核心信息通过指标卡、趋势图、列表和详情抽屉分层呈现，既能支持汇报场景中的快速浏览，也能支持原型评审中的深入点击验证。

| 设计原则 | 实现方式 |
| --- | --- |
| 信息分层 | 一级导航、模块标题、统计卡片、列表与详情抽屉逐层展开 |
| 风险可读 | 使用高危、中危、低危状态与颜色区分事件优先级 |
| 场景一致 | 场景分析六个子模块统一采用统计、查询、列表、详情结构 |
| 企业质感 | 使用蓝白配色、轻量阴影、细分割线和紧凑表格构建控制台观感 |
| 演示友好 | 通过内置样例数据展示完整安全运营链路，便于产品讲解 |

## 数据与安全说明

项目中的所有事件、IP、资产名称、攻击证据、用户名称和业务系统名称均为演示用途。当前版本不会连接真实生产数据库，也不会主动采集用户环境中的安全日志。若后续需要接入真实云流量、告警平台、SIEM、SOAR 或资产管理系统，建议先补充接口契约、权限模型、数据脱敏策略和审计日志方案。
